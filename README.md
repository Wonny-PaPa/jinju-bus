# 진주 버스 — 간단 설치형 PWA (manifest 방식)

본 버전은 `manifest.webmanifest`와 앱 아이콘으로 설치할 수 있도록 구성했습니다. **Service Worker(sw.js)는 포함하지 않았습니다.** 기존 진주 버스 조회·직통·환승 로직과 UI 및 이전에 개선된 네이버지도 앱/웹 연동은 변경하지 않았습니다.

## GitHub Pages에 올리기

1. ZIP 압축을 푼 뒤 `index.html`, `manifest.webmanifest`, `icon.png`, `icon-192.png`, `icon-512.png`, `.nojekyll`을 **기존 저장소의 `index.html`과 같은 폴더**에 올립니다. ZIP 파일 자체를 업로드하는 것이 아닙니다.
2. `Settings → Pages`에서 배포 브랜치가 `main`, 경로가 `/(root)`인지 확인합니다. 기존 배포 경로가 다른 경우 해당 경로를 유지합니다.
3. 배포된 HTTPS 주소(`https://<계정>.github.io/<저장소>/`)에 갤럭시 Chrome으로 접속합니다.
4. Chrome `⋮ → 앱 설치` 또는 `홈 화면에 추가`를 선택합니다. 브라우저/기기에 따라 메뉴 이름이 다릅니다.

## 주의 사항

- 설치형 PWA도 인터넷 및 진주시 데이터 API가 필요합니다. 매니페스트만으로 CORS/API 장애가 해결되는 것은 아닙니다.
- 기존 버전에 `sw.js`를 배포한 적이 있고 캐시 때문에 갱신이 안 된다면 Chrome 사이트 데이터 삭제 후 다시 실행하거나 기존 PWA를 삭제하고 재설치하세요. 새 버전은 `sw.js`를 등록하지 않습니다.
- 공개 GitHub 저장소에 넣는 `index.html`에는 공공데이터 API 키가 포함될 수 있습니다. 사용량 제한·키 공개에 주의하고, 안전하게 운영하려면 API 요청을 백엔드로 중계하세요.
- 네이버지도 앱 연동은 휴대폰 브라우저와 앱 설치 상태 등에 따라 다를 수 있습니다. 앱 링크가 동작하지 않으면 화면의 웹 길찾기 링크를 이용하세요.
